# carbon-inta# Calm Reports: Carbon Footprint Data Intake Engine

A lightweight automation tool built for sustainability consultants to streamline Scope 1-2-3 data collection, eliminate spreadsheet errors, and validate client inputs automatically via Google Apps Script and Python.

### ✨ Features:
- **Automatic Validation:** Instantly flags errors with 'STOP' warnings when client inputs don't match.
- **Frictionless Data Intake:** Transforms messy spreadsheets into a structured, standardized workbook.
- **Time Saver:** Reduces data collection and auditing time from weeks to hours.ke-engine
